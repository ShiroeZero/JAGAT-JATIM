# JAGAT V6.5.3 — Attention Engine

## Tujuan
V6.5.3 mempertahankan fondasi JAGAT V6.5 tetapi merapikan penilaian atensi agar konsisten, dapat dijelaskan, dan benar-benar berguna untuk filter.

## Skala atensi
- 0–39 = Rendah
- 40–69 = Sedang
- 70–100 = Tinggi

Angka 0–100 dipakai untuk ranking. Tiga tingkat dipakai untuk filter operasional.

## Dimensi penilaian
- Keparahan isu
- Hubungan Polri/personel dengan peristiwa
- Dampak publik/institusional
- Status penanganan
- Bukti/keterhubungan sumber
- Penyebaran lintas sumber
- Eskalasi
- Aktivitas hari ini

Keyword hanya evidence; keyword tidak langsung menentukan prioritas.

## Perlakuan penting
- Penegakan hukum normal tidak otomatis menjadi atensi tinggi hanya karena mengandung kata “narkoba”, “tersangka”, atau “ditangkap”.
- “Langgar SOP”, “penyalahgunaan wewenang”, “belum tersentuh”, dan sinyal serupa mendapat perlakuan semantik tersendiri.
- “Belum ditangani” menjadi indikator ketidakselesaian, bukan kesimpulan bahwa terjadi pembiaran.
- Dugaan pelanggaran berat mendapatkan floor agar tidak jatuh menjadi rendah hanya karena satu sumber.
- Case priority tetap melekat pada Case; aktivitas hari ini dihitung terpisah.

## Non-AI
V6.5.3 adalah distribusi non-AI. Workflow tidak memerlukan OPENAI_API_KEY.
