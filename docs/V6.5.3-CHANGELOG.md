# JAGAT V6.5.3

Context-aware deterministic classification without external AI.

## Perubahan utama
- Phrase/context classifier: membaca rangkaian frasa, bukan token tunggal.
- Pisahkan sifat berita, hubungan Polri, jenis isu, dan status penanganan.
- Penegakan hukum oleh Polri tidak otomatis menjadi prioritas tinggi.
- Dugaan pelanggaran personel seperti pungli, suap, lepas tangkap, SOP, kekerasan, dan intimidasi mendapat bobot lebih tinggi bila konteks menunjukkan Polri sebagai subjek masalah.
- Kejahatan berat oleh pihak non-Polri tetap negatif, tetapi tidak otomatis menjadi prioritas tinggi bila Polri hanya sebagai penindak.
- Berita positif penegakan hukum dikenali melalui pola keberhasilan/tindakan, bukan kata tunggal.
- Skala Atensi tetap 0-100 dengan level Rendah (0-39), Sedang (40-69), Tinggi (70-100).
- Evidence dan alasan skor disimpan agar hasil dapat dijelaskan.
- Tidak membutuhkan API eksternal atau OpenAI.
