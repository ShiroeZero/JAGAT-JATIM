# JAGAT V6.1 — Perbaikan Utama

## Fokus
JAGAT difokuskan pada pemantauan pemberitaan yang berkaitan dengan Jawa Timur. Berita dari luar Jawa Timur tetap dapat tersaring oleh query umum, tetapi dinormalisasi sebagai `LUAR JATIM`.

## Perbaikan
1. Dashboard hanya memakai temuan Jawa Timur pada hari berjalan.
2. Geografi ditentukan dari judul artikel; nama publisher/media tidak digunakan sebagai bukti lokasi.
3. Setiap data memiliki `area_label`: Polres Jawa Timur, `Jawa Timur`, atau `LUAR JATIM`.
4. Filter Monitoring memakai `news.json` penuh + rentang tanggal yang benar-benar diterapkan.
5. Filter prioritas memakai prioritas Case untuk artikel yang terkait Case.
6. Detail Case mengambil seluruh `article_ids` yang cocok dari dataset aktif/snapshot.
7. Arsip memiliki dataset News + Case sendiri dan tidak bercampur dengan live data.
8. Judul view tidak diduplikasi oleh banner internal.
9. Collector tidak lagi membuat query satu per satu untuk seluruh provinsi Indonesia.
10. Discovery tetap diperkuat dengan vocabulary 2026 yang diberikan pengguna dan query targeted untuk 39 Polres + Polda Jatim.
11. Workflow Pages menyalin folder `assets/` sehingga logo/favicons ikut ter-deploy.
