# JAGAT V6.5 — Changelog

## Lokasi dan entitas
- Satu resolver lokasi menjadi sumber kebenaran lintas collector, normalizer, Case Engine, validator, dan frontend.
- `Batu Bara` diproteksi agar tidak menjadi `Batu`.
- Nama tempat seperti `Tanjung Perak` tidak otomatis dianggap nama Polres.
- Polsek berfungsi sebagai secondary identity binding untuk Polres, bukan filter wilayah utama.
- Ditambahkan status `BELUM TERPETAKAN`.

## Analisis
- Ditambahkan Skala Atensi 0–100.
- Ditambahkan taxonomy isu dan status penanganan.
- Sinyal seperti `langgar SOP` dan `belum tersentuh` masuk ke analisis, bukan sekadar tag.
- Evidence skor disimpan agar alasan atensi dapat dijelaskan.
- Discovery metadata dibatasi agar tidak terjadi tag explosion.

## Data dan Case
- Case memakai hard boundary untuk Polres eksplisit yang berbeda.
- Aktivitas harian memakai `collected_at` lebih dahulu.
- Validasi global dan Jawa Timur dipisahkan.
- Validator melakukan pemeriksaan semantik lokasi selain pemeriksaan jumlah.

## Frontend
- Filter lokasi menjadikan Jawa Timur sebagai parent filter.
- Pilihan Polres dibuat dinamis sesuai dataset aktif.
- Filter prioritas menggunakan Skala Atensi.
- Dashboard wilayah membuka drawer seluruh berita wilayah tanpa berpindah ke Monitoring.
- Salin tautan dan Buka sumber tersedia pada kartu berita, Case, dan detail.
- Input dan select menggunakan tema gelap; tipografi diperbesar.

## V6.5.1 — AI Case Adjudicator
- Menambahkan triase AI opsional untuk mempromosikan artikel yang secara semantik layak masuk Case Engine.
- AI tidak menentukan lokasi, tanggal, URL, Case ID, atau prioritas final.
- Hanya kandidat yang relevan yang dikirim untuk menjaga biaya dan latensi tetap terkendali.
- Memperbaiki validator agar menghitung `active_today` dengan definisi tanggal yang sama dengan Case Engine.
- Workflow menempatkan AI review sebelum Case Engine dan tetap fallback ke aturan deterministik bila API tidak tersedia.
