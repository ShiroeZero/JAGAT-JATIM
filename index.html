Konfigurasi

URL Supabase dan publishable key dibaca dari config.js. Keduanya aman untuk berada di frontend selama database memakai Row Level Security dan Anda tidak pernah memasukkan service-role key.

Sumber monitoring

Pipeline menggunakan Google News RSS dengan beberapa kombinasi kata kunci Polri/oknum/anggota dan istilah pelanggaran. Ini adalah agregator, bukan jaminan seluruh berita di internet.

Catatan analisis

Status “negatif” berarti artikel memenuhi aturan deteksi kata kunci. Ini bukan penetapan bahwa personel bersalah. Verifikasi tetap harus dilakukan terhadap isi berita dan sumber resmi.
